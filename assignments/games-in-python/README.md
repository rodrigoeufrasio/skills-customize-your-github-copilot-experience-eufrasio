
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build the classic Hangman word-guessing game using Python strings, loops, conditionals, and user input.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description

Create a Hangman game that randomly selects a secret word and lets the player guess letters until they win or run out of attempts.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list
- Prompt the player for single-letter guesses
- Display current progress with underscores for hidden letters
- Track and display remaining incorrect guesses
- End with a win message when the word is fully guessed
- End with a game over message when attempts are exhausted

### 🛠️ Improve Game Feedback

#### Description

Add clear feedback and input validation so the game is easy to play and handles invalid input gracefully.

#### Requirements
Completed program should:

- Show the letters guessed so far after each turn
- Ignore repeated guesses and prompt again without using an attempt
- Accept only a single alphabetic character per guess
- Use functions or a clean code structure for readability
